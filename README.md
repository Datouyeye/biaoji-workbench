# 打标工作台（网页版）

本地数据处理工作台，单文件 HTML 应用，所有数据只在本机读写，不上传任何服务器。

## 使用方式

1. 打开页面（本地双击 `打标工作台.html`，或访问 GitHub Pages 网址）
2. 点「选择 projects 文件夹」，授权访问本机的 projects 目录
3. 之后所有导入、预处理、打标往返操作都在页面内完成

首次授权后浏览器会记住，下次打开自动恢复。

## 技术说明

- 单文件 HTML，SheetJS 已内联，断网可用
- 使用 File System Access API 直接读写本地文件夹，数据零上传
- 需要 Chrome 或 Edge（Safari / Firefox 不支持目录授权）

## 范围

当前版本覆盖阶段 1-3：项目新建、原始数据导入、预处理（筛选拆分 / 规整去重 / 按站点拆分）、打标往返。

阶段 4 及之后的统一化、复核、抽检、汇总等流程仍由本地 Python 工具处理，两者共用同一个 projects 文件夹与 state.json。
